## Fix before the next push

1. **The app reboots every time the phone wakes, and every hour.** `src/App.tsx:128` sets the
   session on every auth event and `:148-155` runs `boot()` whenever the session object
   changes. auth-js re-emits `SIGNED_IN` with a new object on every hidden-to-visible
   transition and `TOKEN_REFRESHED` hourly, so each resume shows "Loading your group…",
   unmounts the store and every page, reruns the 11 load queries, and registers another set
   of outbox `online`/`visibilitychange` listeners that are never removed. Mid-round, the Hole
   view resets; a half-typed form or open bet editor is wiped. Fix: key the effect on
   `session?.user.id`, not the object.
2. **Trip page crashes on an unscored round.** `src/components/TripBooked.tsx:219` reads
   `standings[0].playerId`; `roundStandings` returns `[]` when nobody has a score. Start
   scoring a trip round, open the trip: white page. Guard it and show "No scores yet".
3. **No error boundary.** Any render throw (item 2, the `!` lookups of `me` in Home, Profile,
   Group, Wrapped) is a blank page with no way back. Wrap `<Outlet />` in Shell with a
   boundary that renders the existing `Splash` error card.
4. **Service worker cache grows without bound.** `useNewVersion.ts:32` fetches
   `/index.html?check=<ts>` every 10 minutes and on resume; `public/sw.js:82` treats it as an
   asset and `cache.put`s a unique entry each time. Old hashed bundles are kept across deploys
   too. Fix: only cache-first `/assets/`, `/logos/`, `/splash/` and icons; also check
   `response.ok` at `sw.js:72` before storing a navigation as the offline shell.
5. **Anyone with the anon key can list every photo and logo.** The three storage `select`
   policies (`schema.sql:313, 331, 344`) are `bucket_id = ...` for `public`, so
   `storage.from('player-photos').list('')` enumerates all paths; public buckets don't need a
   select policy for URL downloads. Fix: `to authenticated` and scope to
   `(storage.foldername(name))[1] = current_group_id()::text`. The only in-app listing
   (`round.delete`) stays inside the group folder.
6. **scan-card and course-lookup are open to any Supabase account.** `SignIn.tsx:68` calls
   `signInWithOtp` without `shouldCreateUser: false`, so a stranger can mint an account and a
   JWT; both functions only check `getUser()`, not group membership
   (`scan-card/index.ts:189`, `course-lookup/index.ts:122`). That is 20 Opus image calls a day
   per throwaway account and the whole 35/day GolfCourseAPI quota. Fix: resolve the caller to a
   player row the way `notify` does and 403 otherwise; add `shouldCreateUser: false`.

## Worth fixing soon

7. **A queued score can be dropped as poison after a long sleep.** When the token has expired
   and the refresh fails, supabase-js sends the next request as `anon`; the RLS 401 doesn't
   match `looksLikeConnectivity` (`outbox.ts:71-76`) so `:102-109` discards the change. Treat
   401/`PGRST301` as retryable, or check `getSession()` in `supabaseBackend.apply`.
8. **Bets charge golfers no longer on the round.** `bets.ts:105, 129, 218, 345` pay from
   `playerIds` while scoring uses `entries`; a golfer removed after the bet was placed still
   loses money. Pay from `entries`.
9. **Nassau net with no stroke index uses the raw decimal index** (`bets.ts:204`), so 16.9 vs
   17.0 on identical cards "wins" all three segments. Round `playingHandicap * allowance`.
10. **`teeFor` never matches a tee named "White Tees"** (`courses.ts`, tee lookup): the round
    side strips "tees" and the course side does not, so rating/slope fall back to the course
    default while yards match. Latent today (prod tee names are bare colours) but the
    directory import could introduce it. Reuse `teeKey` on both sides.
11. **`courseForRound` throws when a nine's tee has no `holeYards`** (`courses.ts:189`).
    Hand-edited jsonb takes down every screen for that course. `(t.holeYards ?? [])`.
12. **Winner-take-all skins leaves fractional cents** (`bets.ts:130-131`): three tied leaders
    on a $5 stake sum to +$0.01, so Standings money doesn't net to zero. Split in integer
    cents with the remainder to the first leaders (the `money.ts` pattern).
13. **Avatar photo failure is sticky** (`ui.tsx:19`): one failed load (no signal, cross-origin
    so never cached) means initials for the whole session, including a photo just uploaded.
    Track the failed URL instead of a boolean.
14. **Old photo or logo is deleted before the row update is confirmed**
    (`EditGolfer.tsx:72-73`, `CourseBrandEditor.tsx:96-110`). If the upsert queues or is
    refused, every other phone keeps a dead URL. Delete after the backend confirms.
15. **`course.upsert` conflicts on `(group_id, slug)` while sending `id`**
    (`supabaseBackend.ts:369`): two phones adding the same course offline, or a queued save
    after a rename, collide and get dropped. Upsert on `id`.
16. **Faces on a real iPhone photo is unverified.** `facePhoto.ts:62` uses
    `createImageBitmap(file)` with no `imageOrientation`; a portrait JPEG with EXIF rotation
    may reach MediaPipe sideways. Decode through an `<img>` or pass
    `{ imageOrientation: 'from-image' }`, and give a friendly error for HEIC/corrupt files.
17. **HoleEntry exit paths.** The 800 ms commit timer isn't flushed on unmount
    (`HoleEntry.tsx:87, 272`); `done()` writes a round upsert plus one per bet even with no
    edits (`:474`); clearing a hole keeps the stale gross (`:240`); `markGreenHere` has no
    catch (`:709`).
18. **Wrapped badges are all-time, not the season's** (`wrapped.ts:391`); ghost options include
    partial cards (`ghost.ts:27`); `skinsWon` double-counts across overlapping skins bets
    (`badges.ts:129`); `useLiveWind` keeps a stale wind when the key goes null
    (`liveWind.ts:38`).
19. **`link-preview` is an open fetch proxy** (`netlify/functions/link-preview.js:38-60`): no
    origin check, follows redirects, no private-IP check, reads the whole body. Burns Netlify
    invocations. Check the origin header or allowlist hosts.
